Binomial Coefficient

Binomial Theorem
\[\binom{n}{k} = \frac{n!}{k!(n - k)!}\]

Number of ways to choose k items from n; also the coefficients in a binomial expansion.

Variables & example
  • \(n\) total items
  • \(k\) items chosen

Conditions: 0 ≤ k ≤ n, integers

Example: n = 5, k = 2 → 10

fact(n) / (fact(k) * fact(n - k))

Binomial Theorem
\[(a + b)^n = \sum_{k=0}^{n} \binom{n}{k} a^{n-k} b^k\]

Variables & example

Example: n = 5, k = 2, a = 2, b = 3 → 720 — C(5,2)·2³·3² = 10·8·9.

Mean Value Theorem

Applications of Derivatives
\[f'(c) = \frac{f(b) - f(a)}{b - a}\]

Some point c in (a, b) has an instantaneous rate equal to the average rate over [a, b]. The value computed is that required slope f′(c).

Variables & example
  • \(f(a)\) function value at a
  • \(f(b)\) function value at b
  • \(a\) left endpoint
  • \(b\) right endpoint

Conditions: f continuous on [a, b] and differentiable on (a, b)

Example: fa = 0, fb = 8, a = 0, b = 2 → 4 — f(x) = x³ on [0, 2]; 3c² = 4 gives c = 2/√3.

(fb - fa) / (b - a)
